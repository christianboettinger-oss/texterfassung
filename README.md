# AMZMANAGER Texterfassung

Erfassungsmaske für Amazon-Verkaufstexte. Läuft vollständig im Browser, es werden keine Daten hochgeladen.

1. Maske öffnen und ausfüllen
2. „Paket erzeugen“ – das ZIP landet im Download-Ordner
3. ZIP in Claude ziehen: „Hier ist das Texterfassungspaket, bitte die Verkaufstexte erstellen.“
